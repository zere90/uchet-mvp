## Критерии приёмки (PRD, раздел 13)

- [ ] Проведённый документ нельзя отредактировать, пока не отменено проведение
- [ ] Повторное проведение не удваивает движения
- [ ] После отмены проведения в регистрах не остаётся строк с этим регистратором
- [ ] По каждому документу дебет = кредит = сумма документа
- [ ] Остаток по складу совпадает с суммой введённых накладных
- [ ] 20 накладных совпадают с 1С
- [x] Нумерация не даёт дублей и разрывов при одновременной работе
- [ ] Проведение 1000 документов укладывается в норматив
- [ ] Правило проводок меняется администратором без релиза
- [ ] Все действия с документами видны в журнале аудита
